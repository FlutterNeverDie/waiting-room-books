# 웨이팅룸 코드 읽기

서버 · 인프라가 처음인 주니어 개발자를 위한 waiting-room 코드 읽기 책 (5권).

- 웹: https://flutterneverdie.github.io/waiting-room-books/
- 내용: `build/vol1.js` ~ `vol5.js`, 엔진 `build/engine.html`
- 로컬 빌드: `cd build && python3 -I build.py` → `웨이팅룸_코드_읽기.html`
- main에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 빌드해서 Pages에 올린다
- 고치는 법: `고치는_법.md`
